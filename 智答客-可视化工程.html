02 · POSITION项目定位

面向企业的私有化智能客服平台：大模型对话 + 多来源知识库检索，支持文档知识入库、精准问答、流式响应与多轮会话，并提供可嵌入对外业务的客服 SDK，形成「知识 → 检索 → 应答 → 集成」的完整闭环。

从零独立设计、开发与交付——覆盖后端服务、前端应用、知识库与向量检索、对外 SDK 的完整产品。

03 · METHODOLOGY工程方法论

贯穿项目全过程的思考方式——可迁移、可复用，与具体业务解耦。

M-01

RAG 全链路工程化

对「文档解析 → 切片 → 向量化 → 检索 → 问题改写 → 生成」完整链路做工程化设计：每一环都可观测、可调优。

M-02

多来源知识统一抽象

将不同来源的知识库抽象为统一检索接口，业务侧无感切换；本地向量库与云端知识服务并存，兼顾数据自主与扩展。

M-03

产品化与 SDK 思维

不止做「能聊天的系统」，还产出对外可嵌入的客服 SDK 与生成器页面——把能力封装为可集成、可配置的产品形态。

M-04

可靠性设计

流式响应全链路、重试机制、并发控制、会话安全与健康探活——让系统在真实负载下可用、可监控、可恢复。

M-05

测试与文档双驱动

多套自动化测试保障行为稳定；文档与代码同步演进，让系统可接手、可维护、可交付。

M-06

容器化交付

基于容器编排的整体交付，配套健康检查与配置化运行，简化部署与迁移成本。
