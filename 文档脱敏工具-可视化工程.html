02 · POSITION项目定位

面向文档隐私保护场景的脱敏工具：把含有敏感信息的文档转换为可安全外发/共享的版本，同时保留可追溯的映射关系。核心价值在于「识得准、脱得净、可追溯」——敏感项被替换为随机串，映射关系留档供需要时还原。

隐私保护的工程落点：不是简单地替换字符，而是让「识别 → 确认 → 脱敏 → 审计」成为一条闭环、可控、可信的流水线。

03 · METHODOLOGY工程方法论

贯穿设计、开发与交付的思考方式——可迁移、可复用。

M-01

闭环设计，防漏可追溯

识别 → 人工确认 → 脱敏 → 映射留档 → 审计，每一步都有据可查。脱敏不是一次性替换，而是可解释、可还原、可审计的完整闭环。

M-02

规则 + LLM 双通道

确定性规则引擎保证覆盖率与可复现，LLM 辅助识别提升对非结构化敏感信息的发现能力；两者可离线、可切换，不绑定单一模型。

M-03

隐私优先的架构

会话级临时处理、不落库、可本地/内网部署——工具自身的架构同样遵循隐私最小化原则，处理的数据不被留存、不被外发。

M-04

AI 工程化开发方式

以多 Agent 团队（诊断 / 实现 / 验证）+ Skill 工程（计划 / 报告）+ 三道门控流水线完成开发——把 AI 从辅助工具推进为可编排、可治理的开发流程。

M-05

前后端工程化

现代前端框架 + 服务端分层架构，静态构建、容器化部署，面向内网环境的完整交付链路。

M-06

质量先行

自动化测试基线随功能同步演进，每次改动有可复现的验证手段；环境受限时如实标注，不掩盖验证缺口。
