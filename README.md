# Showcase · 工程作品集

个人工程与能力档案的统一展示索引。纯前端静态 HTML，本地双击 `index.html` 即可浏览全部分支页面，无需构建、无需依赖。

## 包含什么

- **索引首页**：统一入口，卡片式跳转到每个工程与能力档案
- **能力档案 ×4**：面向业务价值提炼的方法论档案（私有化知识问答 / 智能客服 / 数据脱敏 / AI 运维工程）
- **可视化工程 ×5**：Harness 编排方法论、数字员工大脑、多智能体编排等工程的可视化展示

## 工程清单

| 入口 | 类型 | 说明 |

| 索引首页 `index.html` | 总览 | 全部展示资产的统一入口 |
| `企业私有化知识平台-能力档案.html` | 能力档案 | RAG 方法论落地档案：问答链路、检索优化、评测驱动 |
| `智答客-能力档案.html` | 能力档案 | IM 智能客服产品能力档案 |

| `AI运维工程-能力档案.html` | 能力档案 | AI 驱动的运维工程化方法论档案 |
| `harness-team-visual/` | 可视化工程 | Harness 多 Agent 团队编排方法论可视化 |

## 使用方式

```bash
git clone git@github.com:siYuanJun/showcase.git
cd showcase
open index.html
```

## 说明

- 目录内 `skill-flow-viz` 与 `ontology-brain-visual` 为两个独立公开仓库的线上展示入口，本仓库索引页直接跳转其 GitHub Pages 地址，不在本仓库内重复维护源码
- 所有页面为纯静态 HTML，可直接本地打开或托管至任意静态站点服务
